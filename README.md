# Portfolio

Personal portfolio

## Tech Stack

- React
- TypeScript
- Vite
- pnpm
- GitHub Pages

## Development

Install dependencies:

```bash
pnpm install
```

Run the local dev server:

```bash
pnpm dev
```

Open:

```txt
http://localhost:5173
```

## Build

Create a production build:

```bash
pnpm build
```

The build output is generated in:

```txt
dist/
```

## Preview

Preview the production build locally:

```bash
pnpm preview
```

## Deployment

The site is deployed to GitHub Pages.

The app uses Vite with:

```ts
base: '/portfolio/'
```
